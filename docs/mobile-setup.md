# 手机端安装与使用

面向 iPhone / iPad 用户。Android 步骤相同，只是「文件」App 换成系统文件管理器。

---

## 一、先选一种方式

|                | 方式 A：浏览器    | 方式 B：Obsidian 插件  |
| -------------- | ----------------- | ---------------------- |
| 需要安装       | 不用              | 要在手机上放 3 个文件  |
| 上传下载       | ✅ 一样           | ✅ 一样                |
| 下载文件落到哪 | iOS「下载」文件夹 | 直接进 vault，双链可用 |
| 适合           | 先跑通、临时用    | 日常使用               |

两种可以同时用，互不冲突。

---

## 二、方式 A：手机浏览器

1. 电脑端 Obsidian 打开 **Vault Bridge 设置页**，点一下那条局域网地址（会自动复制整条带令牌的链接）。
2. 用微信/邮件/AirDrop 把链接发到手机，或用手机浏览器手动输入。
3. 打开后：

   - **点文件夹**进入下一级，**点文件**直接下载；
   - 底部「**上传到此**」把手机里的文件传到当前目录；
   - 「新建」可建文件夹，「刷新」重新拉取列表。

4. 建议加入主屏幕：Safari 分享按钮 → **添加到主屏幕**，之后像 App 一样点开。

> 令牌会存在浏览器本地，下次打开不用重新输入。
> 想换令牌：页面右上角「切换令牌」。

---

## 三、方式 B：Obsidian 插件

### 第 1 步：下载安装包

手机浏览器打开：

```
http://<电脑的局域网IP>:8770/setup
```

这个页面**不需要令牌**也能打开，里面有当前地址、令牌和一键下载按钮。

点「**下载插件安装包（zip）**」→ 系统询问时选「**存储到"文件"**」。

### 第 2 步：解压

打开「文件」App → 「下载」→ 找到 `vault-bridge-plugin.zip` → **轻点一次**，系统自动解压出一个同名文件夹。

里面有 3 个文件：`main.js`、`manifest.json`、`styles.css`。

### 第 3 步：放进 vault

1. 在「文件」App 里找到你的手机 vault 目录：

   - 本地库：`我的 iPhone → Obsidian → <你的库名>`
   - iCloud 库：`iCloud 云盘 → Obsidian → <你的库名>`

2. 进入 `.obsidian` → `plugins`（没有 `plugins` 就新建一个）。

3. 在 `plugins` 里新建文件夹，名字必须是 `vault-bridge`（全小写、中间是减号）。

4. 把解压出的 3 个文件**移动**进 `vault-bridge` 文件夹。

最终结构：

```
<你的库名>/.obsidian/plugins/vault-bridge/
├── main.js
├── manifest.json
└── styles.css
```

> **看不到 `.obsidian`？** iOS 的「文件」App 会显示以点开头的文件夹，
> 但要注意别停在「最近使用」里，必须从「浏览 → 我的 iPhone / iCloud 云盘」逐层进入。

### 第 4 步：启用插件

Obsidian → 设置 → **第三方插件**：

1. 先关闭「**受限模式**」（仅首次需要）；
2. 在「已安装插件」里找到 **Vault Bridge**，打开开关。

### 第 5 步：连接电脑

1. 点左侧边栏的 ⇄ 图标，或命令面板搜「Vault Bridge 打开传输面板」。
2. 顶部「电脑地址」填 `http://<电脑IP>:8770`，点「连接」。
3. 令牌已经在电脑端设置页里，首次可在传输面板的「⚙ 设置」里粘贴。

连接成功后标题旁的小圆点变绿。

## 四、日常使用

### 下载到手机：整库一次同步（最常用）

1. 切到「**⬇ 下载到手机**」页签，确认顶部小圆点是绿的（已连接）；
2. 点页签下方的通栏按钮 **「⬇ 一键同步整个库到手机」**；
3. 首次会把电脑上所有文件按原目录结构搬到手机，进度显示在按钮下方；
4. 之后再点一次，只传改动过的文件：大小与修改时间都没变的会自动跳过，几秒钟结束。

同步结束会如实汇报四个数字：**下载 N 个 / 跳过 M 个未变化 / 失败 K 个 / 无法读取 X 个目录**。
若某项不为 0，按提示重试即可，已传完的文件不会重传。

> 想快一点：手机与电脑连同一个 WiFi，整库会走局域网直连，不经公网。

### 下载到手机：按需单独下载

1. 逐层进入电脑上的目录；
2. **点文件**即下载，**点文件夹**递归下载整个目录（带进度）；
3. 文件按电脑上的相对路径落到手机：

   ```
   电脑: 团队知识库/IHM2/需求清单.md
   手机: VaultBridge下载/团队知识库/IHM2/需求清单.md
   ```

   保持结构是为了让 Obsidian 的双链、附件引用在手机上依然有效。
   落地目录可在设置里改。

### 上传到电脑

1. 切到「**⬆ 上传到电脑**」页签；
2. 浏览手机上的目录（默认从 vault 根开始）；
3. **点文件**上传，**点文件夹**整目录上传；
4. 文件落到电脑设置里的「上传到电脑的目标目录」，留空则落到电脑 vault 根。

### 设置页里也能直接动作（填完地址不知道点哪时看这里）

Obsidian → 设置 → **Vault Bridge** → 「手机端」分组的第一项「**连接检查与一键同步**」：

| 按钮                 | 作用                                                                          |
| -------------------- | ----------------------------------------------------------------------------- |
| 测试连接（检查 200） | 请求一次 `/api/health` 并校验令牌，把「HTTP 200 · 版本 · 耗时」写在下方状态行 |
| ⬇ 一键同步整个库     | 不必打开面板，直接在设置页把电脑上的文件全部同步到手机                        |
| 打开传输面板         | 打开带目录浏览的传输面板（面板顶部同样有连接与同步入口）                      |

### 设置项

| 设置                 | 作用                                                       |
| -------------------- | ---------------------------------------------------------- |
| 电脑地址             | 局域网填 `http://192.168.1.44:8770`；外网填 https 隧道地址 |
| 下载保存到手机的目录 | 默认 `VaultBridge下载`                                     |
| 上传到电脑的目标目录 | 留空 = 电脑 vault 根目录                                   |
| 单次上传上限         | 默认 32 MB，手机内存有限，不建议调太大                     |

## 五、更新插件（不用再手动换文件）

电脑端出了新版本后，手机上不必再解压、复制三个文件：

1. 手机 Obsidian 打开传输面板，确认已连接电脑；
2. 点页脚 **「⇧ 更新插件」**；
3. 提示更新成功后，重启 Obsidian（或重新加载界面），新版本即生效。

> 原理：电脑端在同一条地址上提供了插件自己的三个文件（`/setup/file?name=…`），
> 手机端取回来覆盖本机插件目录，manifest 最后写——中途失败时本机仍是能用的旧版本；
> 取回的 manifest 会先校验 id 是不是 `vault-bridge`，不是就中止，绝不会拿别的插件覆盖自己。

只有**第一次安装**（手机上还没有这个插件）才需要走第三节的手动 zip 流程。

> 设置页「手机端」分组的第一项「**连接检查与一键同步**」里还有三个按钮：
> **测试连接（检查 200）**（请求一次 `/api/health`，把 HTTP 状态、版本、耗时写在下方状态行）、
> **⬇ 一键同步整个库**（不必打开面板就能整库同步）、**打开传输面板**。
> 看不到这些按钮 = 插件版本旧于 **1.0.6**，先按本节更新插件。

## 六、在外网使用（4G/5G）

局域网地址在外网不可用，需要电脑上开一条公网隧道：

```bash
tools/tunnel.sh start
```

它会打印一个 `https://xxx.trycloudflare.com` 地址，把这个地址填进手机的「电脑地址」即可。

注意：

- 必须是 **https**。iOS 的传输安全策略会拦截明文 http；
- 快速隧道的域名**每次重启都会变**，变了就在手机上改一次地址，令牌不用改；
- 回到家里/公司 WiFi 后，把地址改回局域网地址，速度更快、也不经过公网。

## 七、故障排查

| 现象                              | 原因与处理                                                                                       |
| --------------------------------- | ------------------------------------------------------------------------------------------------ |
| 提示「连不上电脑」                | 电脑端服务没开；或手机与电脑不在同一 WiFi；或地址/端口写错                                       |
| 提示「令牌无效」                  | 电脑端点过「重新生成」，需要在手机上更新令牌                                                     |
| 提示「已被临时限流」              | 连续输错 8 次，等 5 分钟；或在电脑端重启服务解锁                                                 |
| 浏览器能打开但插件连不上          | 外网场景下用了 `http://`，改成 `https://` 隧道地址                                               |
| 上传大文件失败                    | 超过上限（默认 32 MB），或在电脑端设置里调大上限                                                 |
| 下载后文件没出现在 Obsidian       | 确认落地目录与当前打开的 vault 是同一个；下拉刷新文件列表                                        |
| 面板里看不到「一键同步整个库」    | 插件版本旧于 1.0.5，先点「⇧ 更新插件」再重启；按钮在「下载到手机」页签正下方，未连接电脑时是灰的 |
| 一键同步提示「失败 K 个」         | 已经传完的文件不会重传，直接再点一次即可；连续失败看电脑端访问日志                               |
| 一键同步提示「无法读取 N 个目录」 | 这些目录被电脑端排除或读取被拒，其余文件已同步，属正常保护                                       |

判断链路的最快方法：手机浏览器打开

```
http://<电脑IP>:8770/api/health
```

- 返回 JSON → 网络通、服务正常；
- 返回 `{"error":"unauthorized"}` 之类 → 网络通，是令牌问题；
- 打不开 → 网络或端口问题。
