手机安装指南

两种方式任选其一，第一种立刻能用，第二种体验更好。

方式一 · 手机浏览器 推荐先试

不用装任何东西，打开网页就能上传下载，功能与插件版一致。
访问地址读取中…
访问令牌未携带
打开传输页面
把这个页面加入主屏幕（Safari 分享 → 添加到主屏幕），下次点图标即可使用，和 App 一样。

方式二 · Obsidian 手机插件

在手机上用 Obsidian 原生界面传文件，下载的文件会直接进 vault。
⬇ 下载插件安装包（zip）
  1. 点上面的按钮下载 vault-bridge-plugin.zip，选择「存储到"文件"」。
  2. 在「文件」App 里找到它，轻点一次自动解压出 3 个文件（main.js、manifest.json、styles.css）。
  3. 进入你手机 vault 的目录：…/<你的库名>/.obsidian/plugins/
    没有 plugins 或 vault-bridge 文件夹就新建一个，名字必须完全一致。
  4. 把解压出的 3 个文件移动进 vault-bridge 文件夹。
  5. 回到 Obsidian → 设置 → 第三方插件（先关闭"受限模式"）→ 已安装插件里打开 Vault Bridge。
  6. 点左侧边栏的 ⇄ 图标（或命令面板搜 "Vault Bridge"）打开传输面板，填入上方地址与令牌。
提示：iOS 的「文件」App 能看到以点开头的 .obsidian 文件夹，直接进去即可； 若找不到，请确认在「我的 iPhone / Obsidian」或「iCloud 云盘 / Obsidian」下， 而不是在"最近使用"里。
